# Magrathea 0.1.0-alpha.4

This release contains the changes summarized below.

## Changes

### Added

- Provider failures now distinguish accepted credentials with denied resource access from
  authentication failures across HTTP transport, reference adapters, Runtime failure codes, and
  the Chatbot facade.

### Fixed

- Interrupted OpenAI Responses and Anthropic recovery replays now omit non-portable reasoning
  blocks while preserving replayable answer text and Tool calls instead of rejecting the request.

## Distribution

The 16 logical SDK modules and their Kotlin Multiplatform variants are published under
`saien.magrathea` in GitHub Packages. Consumer configuration is documented in
[Publishing](../publishing.md#consume).

The release assets include the signed Maven-layout bundle, checksum, coordinate inventory,
CycloneDX SBOM, third-party license report, and immutable release-candidate receipt.

## Notes

This is a prerelease. APIs and persisted formats may still evolve before the stable line. Review the
[known issues](../known-issues.md) before adopting this release.
