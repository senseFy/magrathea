# Magrathea 0.1.0-alpha.2

This Alpha strengthens recoverable Agent execution and introduces typed multimodal Tool results
across Kotlin Multiplatform targets.

## Highlights

- Durable Provider interruption, retry, reattachment, and terminal-abandonment contracts with
  replay-safe checkpoints and commit-before-cleanup ordering.
- Typed Tool text and image content with explicit model/user audiences, stable media references,
  bounded external origin, Provider-native mapping, MCP mapping, and Chatbot projection.
- A Provider-neutral Image Search Tool with an application-supplied backend, Safe Search, source
  attribution, license metadata, stable failure codes, and replay policy.
- Gateway exact-v2 with typed Tool attachment references, durable stream replay, idempotent
  cancellation, and bounded terminal tombstones.
- Strict schema-v5 session and checkpoint envelopes for typed Tool content, origin, media, and
  Provider interruption state.

## Compatibility

Gateway clients and servers must both use exact-v2. Persisted Alpha.1 schema-v4 sessions and
checkpoints are not accepted by the schema-v5 codecs.

## Distribution

The 16 logical SDK modules and their Kotlin Multiplatform variants are signed and published under
`saien.magrathea` in GitHub Packages. Gradle consumers need GitHub Packages credentials with
`read:packages`; setup is documented in
[Publishing](https://github.com/senseFy/magrathea/blob/v0.1.0-alpha.2/docs/publishing.md#consume).
