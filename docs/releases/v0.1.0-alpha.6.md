# Magrathea 0.1.0-alpha.6

This release contains the changes summarized below.

## Changes

### Added

- Hosts can share request-aware execution permits across Tools and Web Search backends to cap
  concurrent calls while keeping admission queue time outside each Tool's execution timeout.

### Changed

- Release status watching now refreshes every ten seconds to reduce authenticated GitHub API
  traffic without changing the guarded release sequence.

## Distribution

The 16 logical SDK modules and their Kotlin Multiplatform variants are published under
`saien.magrathea` in GitHub Packages. Consumer configuration is documented in
[Publishing](../publishing.md#consume).

The release assets include the signed Maven-layout bundle, checksum, coordinate inventory,
CycloneDX SBOM, third-party license report, and immutable release-candidate receipt.

## Notes

This is a prerelease. APIs and persisted formats may still evolve before the stable line. Review the [known issues](../known-issues.md) before adopting this release.
