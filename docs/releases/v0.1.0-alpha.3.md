# Magrathea 0.1.0-alpha.3

This Alpha adds Provider-neutral reasoning controls, establishes the first SDK-owned persistence
migration baseline, and strengthens license evidence across the Kotlin Multiplatform distribution.

## Highlights

- Provider-neutral `Auto`, `Disabled`, and semantic effort preferences validated against
  model-declared capabilities and mapped to exact Provider controls only at adapter boundaries.
- Reasoning configuration across Core, Runtime, Chatbot, Gateway exact-v3, the reference Provider
  adapters, and the JavaScript/TypeScript facade.
- Schema-v6 session and checkpoint envelopes with payload-free failure classification, frozen
  adapters and fixtures, an append-only schema ledger, and contiguous future migrations.
- Atomic Room and IndexedDB rewrite boundaries that publish migrated data only after complete
  validation, while preserving incompatible or corrupt stored bytes.
- Canonical project-license embedding in published archives plus complete Web runtime license and
  source-map provenance checks.

## Compatibility

Gateway clients and servers must both use exact-v3. Persisted schema-v5 sessions and checkpoints
from Alpha.2 are an intentional Alpha clean break and are not accepted by the schema-v6 runtime.
Schema 6 is the permanent migration baseline: future readable schema revisions must provide every
adjacent migration instead of introducing another clean break.

Explicit reasoning preferences require matching trusted model capabilities. `Auto` remains the
portable default and preserves Provider-native configuration that does not conflict with a neutral
override.

## Distribution

The 16 logical SDK modules and their Kotlin Multiplatform variants are signed and published under
`saien.magrathea` in GitHub Packages. Gradle consumers need GitHub Packages credentials with
`read:packages`; setup is documented in
[Publishing](https://github.com/senseFy/magrathea/blob/v0.1.0-alpha.3/docs/publishing.md#consume).

This release includes the complete Maven-layout bundle, SHA-256 checksum, concrete coordinate
