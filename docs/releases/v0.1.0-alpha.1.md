# Magrathea 0.1.0-alpha.1

The first public Alpha of Magrathea: a Kotlin Multiplatform agent runtime for Android,
JVM/Desktop, iOS, browser JS, and experimental browser Wasm.

## Highlights

- Streaming Agent turns with tools, cancellation, retry, resume, checkpoints, and bounded runtime
  policies.
- Token-aware semantic context compaction while preserving authoritative full history.
- Provider-neutral runtime and chatbot APIs with Gemini, OpenAI-compatible, and
  Anthropic-compatible reference adapters.
- Optional MCP, portable Web Search, and cross-model X Search Tool integrations.
- Room and IndexedDB persistence, protected mobile credentials, and a browser-safe Gateway path.

## Distribution

The 16 logical SDK modules and their Kotlin Multiplatform variants are signed and published under
`saien.magrathea` in GitHub Packages. Gradle consumers need GitHub Packages credentials with
`read:packages`; setup is documented in
[Publishing](https://github.com/senseFy/magrathea/blob/v0.1.0-alpha.1/docs/publishing.md#consume).

This Release includes the complete Maven-layout bundle, SHA-256 checksum, concrete coordinate
inventory, CycloneDX SBOM, and third-party license report.
